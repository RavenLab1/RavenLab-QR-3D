# RavenLab QR 3D

واجهة عربية مجانية لتحويل الروابط إلى مجسم QR وتنزيل ملف STL داخل المتصفح، دون إرسال الرابط لخدمة خارجية.

- المقاس: 40 × 40 مم.
- مع قاعدة أو بدون قاعدة.
- سماكة القاعدة وارتفاع الرمز بدءًا من 0.2 مم.
- بدون قاعدة: مربعات منفصلة تحتاج تثبيتًا بترتيبها على سطح فاتح مع هامش فارغ حول الرمز.
- ملفات STL بوحدة المليمتر؛ استوردها بمقياس 100%.

## التشغيل

افتح `index.html` بالمتصفح. لا يتطلب تثبيت مكتبات أو عملية بناء.

## GitHub Pages

من Settings → Pages اختر Deploy from a branch، ثم فرع main ومجلد / (root)، واحفظ.

## الطباعة

استخدم قاعدة فاتحة ورمزًا داكنًا واختبر المسح بعد الطباعة. السماكات الرقيقة تعتمد على الطابعة وارتفاع الطبقة. STL لا يخزن الألوان.
